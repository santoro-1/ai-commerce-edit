# 场景复核与新片验证

核心方法大改后使用。下表是输入与预期判断，不是实际剪完这些新品类的证明；不能靠文字包含某句话就判定审美通过。

| 场景输入 | 预期判断和可观察结果 |
|---|---|
| 1 清洁剂口播开场平，有真实顽固污渍近景 | 判断近景能让问题可见，合理安排前置或插入，声音连续；不凭空强化清洁效果 |
| 2 服装口播指腰围，用户要求手势完整 | 保留手势与相关台词，把面料细节放在后续可覆盖句；不盖掉关键指示 |
| 3 家电只有一个完整开关操作镜头，开头很短 | 选完整有效动作，不为预设镜头数量硬拆两段或要求无用补拍 |
| 4 食品AI酱汁质地与实拍明显不同 | 用适合的实拍承担质地展示，检查动作和声音；不只调色、不循环伪造长过程 |
| 5 产品素材自带参数卡，用户只要求突出卖点 | 检查已有信息，花字概括重点，不再重复同样参数或叠框遮挡 |
| 6 约两秒特写已有明显组合动画，用户问是否加转场 | 根据接点判断，允许硬切并留稳；不机械加长进出转场吞掉观看时间 |
| 7 同批有科普、测评和卡通剧情三个主体 | 分别安排理解节奏、揭晓节奏和动作节奏，品牌可统一；不全片同一种运动和音乐 |
| 8 用户手改了字幕/BGM/复合对比，只要局部景别变化 | 读取最新稿、备份、保留手改与比较条件，用合适关键帧；不重跑旧批量脚本 |
| 9 换了剪映版本，有解密工具但未验证回写 | 检查工具与工程，在副本验证读写链路；不要求回旧版，不直接用明文覆盖原件 |
| 10 用户要求直接剪，新品类没有关键使用镜头 | 完成可独立部分，给具体缺镜头要求与理由；不为新镜头自动调用收费生成，也不逐项询问已授权常规动作 |

复核时写出实际选法、可能代价和待检查点；若与预期不同，依据新素材解释，而非为符合表格强行执行。发现规则冲突做局部修正。

## 本次工作方式的十项复核

这些是行为场景与预期，不要求实际重剪历史草稿。复核要写具体选法和边界，不能仅检查文件里是否有对应句子。

| 场景输入 | 预期判断和可观察结果 |
|---|---|
| 1 用户只要求升级方案，尚未确认 | 只给现状、修改范围与理由，不改技能、版本号或草稿 |
| 2 表格有多个近似标题，草稿台词各不相同 | 本次重读原表，以台词及内容确定对应脚本；无法确认才询问，不按首个关键词命中剪辑 |
| 3 用户已排好段落，让先分析怎么优化 | 识别现有安排，提出针对声画、切点、文字及完成度的方案；不照搬前条或无理由重排 |
| 4 用户刚改字体、位置、BGM和一段变速，只改字幕 | 基于最新保存备份，只处理授权文字范围，保留其他手改；不恢复旧字号或旧速度 |
| 5 用户确认完整第一版，素材有逆光镜头且无BGM | 纳入必要逐镜校色、字幕动效、接点和声音处理；不把这些全推给精修，也不自动新增BGM |
| 6 普通卖点长句容易换行，用户要短重点 | 按语义及声音分屏，保留信息条件，在确认阅读区域突出短词；不同时重复整句花字 |
| 7 另一商品需要步骤卡，用户只确认普通字幕样式 | 普通字幕沿用，步骤卡独立设计并避让；不套用冲锋衣活动双卡配色或圆窗 |
| 8 两镜之间有完整操作动作，邻接处另有场景变化 | 动作保持可见，转场按接点分别选；不固定硬切比例、不用统一长效果盖动作 |
| 9 指定原生动画缺少可用资源 | 明确限制与可行替代，不虚构ID，不用全画面缩放冒充已经添加原生动画 |
| 10 文件回读和合成静帧通过，没原生连续带声播放 | 分开报告已验证范围，列出具体待看接点；不宣称动作、音效、原生兼容性或审美全部通过 |

跨品类迁移另看[冲锋衣案例](jacket-cases.md)的适用条件：圆窗、冷热双屏、多色同屏与独立活动卡都不是必选手法。技术重载问题与审美选择分别记录。

下一条真实新片重点验证：

- 重要剪辑选择是否来自实际素材/声音，用户是否仍需反复纠正同类问题。
- 是否保住关键动作、字幕语义、产品真实性和用户手改。
- 是否既有主体差异和视觉重点，又有足够时间理解内容。
- 工程交付与实际播放结果是否分别有记录。

用户反馈后补充案例和适用条件。未完成真实新片前，只能报告技能结构校验及场景推演结果，不能宣称跨品类效果已经实证。

# 本地工具与剪映草稿读写配置

这是执行条件说明，不改变剪辑风格。核对日期：2026-10-26。适用于希望用本地文件方式修改剪映草稿的使用者；具体工具选择随现有环境调整。

## 先区分技能与执行工具

本技能保存剪辑方法、个人偏好和案例，不包含通用草稿执行器。Agent需要可用的本地文件/命令工具、用户授权的项目和素材，以及当前格式的草稿读写方法。仅下载技能，或只把电脑路径发给不能访问本机的聊天环境，不能直接完成写入。

本次链路是：读取最新保存并备份 → 必要时解密 → 分析并修改工程JSON、准备新增资源 → 回加密和回读 → 在受保护基线上写入 → 静帧、声音及原生审片分别验收。逐片修改脚本按项目编写，不随技能分发；JSON结构和原生效果仍需按实际草稿适配。

## 工具来源与分工

| 条件/工具 | 本次用途 | 其他使用者需要准备什么 |
|---|---|---|
| 本地Agent | 分析文件、编写/运行处理脚本、修改工程 | 可读写目标目录并运行命令；了解本次允许修改的范围 |
| 剪映及项目 | 提供运行时、工程结构与原生资源 | 完整版本号、已保存的草稿目录、素材和实际字体；确认根稿与有效时间线 |
| [jy-draftc](https://github.com/wenshui330/jy-draftc) | 本地草稿JSON解密与回加密 | Windows x64执行链，适配版本的工具包及剪映运行时；明文工程不需要此步骤 |
| [Python](https://www.python.org/downloads/) | 本次工程与媒体处理脚本 | 本次使用64位Python 3.11.9；建议用独立虚拟环境，脚本必须使用装依赖的同一个解释器 |
| [FFmpeg和ffprobe](https://ffmpeg.org/download.html) | 时长/流信息、抽帧、声音和派生媒体 | 将二者所在bin目录加入PATH，或给出各自完整位置 |
| [pyJianYingDraft](https://github.com/GuanYixuan/pyJianYingDraft) | 构建部分文字、片段、转场/动画材料 | 本次安装0.3.0；它不提供本次的加解密。可靠的直接JSON流程可以不依赖它 |
| Pillow、NumPy、openpyxl | 图像预览、音频/数值处理、读取xlsx | 按任务需要安装；不把所有辅助库设成每条视频必装 |
| 字体及原生资源 | 字幕、视频动画、转场和调色 | 使用本机可用或项目已携带的资源；核对文件路径、有效材料引用和使用权限 |

不需要为此安装完整ChatCut、Remotion、云端生成服务或自动导出工具。若实际任务另需这些能力，再按缺口选择。

## Python与媒体工具检查

以下是新环境的可选准备示例，不应覆盖已有可用环境。先在准备放处理脚本的工作目录运行：

```powershell
py -3.11 --version
ffmpeg -version
ffprobe -version
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install "pyJianYingDraft==0.3.0" Pillow numpy openpyxl
.\.venv\Scripts\python.exe -c "import pyJianYingDraft, PIL, numpy, openpyxl; print('imports ok')"
```

已有Python但没有Windows的 `py` 启动器时，用该解释器完整位置替换；不必为此重复安装。只做工程JSON操作时先检查脚本所需库再安装。上游pyJianYingDraft说明推荐其测试使用的Python 3.8或3.11，不能据此断言所有更高版本都不兼容。本次0.3.0是记录的基线，不是永远固定的最新版。

FFmpeg官网提供源码及Windows编译包链接。需要的是可执行的 `ffmpeg` 和 `ffprobe`；只安装同名Python包装库不等于已有这两个命令。

## 加解密项目与配置

**原项目Git地址：[https://github.com/wenshui330/jy-draftc.git](https://github.com/wenshui330/jy-draftc)**。

- 下载：[官方Releases](https://github.com/wenshui330/jy-draftc/releases)。
- 命令与兼容范围：[上游README](https://github.com/wenshui330/jy-draftc#readme)，优先对照下载包自身的README/USAGE。
- 配置：复制工具包中的 `.env.example` 为同目录 `.env`，填写 `JY_INSTALL_DIR`。该值是**包含 `videoeditor.dll` 的剪映版本目录**，不是草稿目录、桌面快捷方式或所有版本的父目录。
- 工具利用使用者本机剪映运行时；本仓库不分发 `videoeditor.dll`。更换剪映版本后需重新核对目录和兼容性。

2026-10-26核对到的上游当前发布为 [v11.6.0.14552-26101320](https://github.com/wenshui330/jy-draftc/releases/tag/v11.6.0.14552-26101320)，对应运行时11.6.0.14552。这是带日期的来源记录，不是要求所有使用者安装该版。按实际剪映选择匹配工具；已有链路可用时，不直接替换exe或强行降级剪映。

### 上游当前接口示例

在解压的工具目录中运行；把占位文字替换为自己的路径，输入使用事先准备的**完整测试副本**：

```powershell
if (-not (Test-Path -LiteralPath .env)) {
    Copy-Item -LiteralPath .env.example -Destination .env
}
```

编辑并保存 `.env`、填好 `JY_INSTALL_DIR` 后，再逐条运行：

```powershell
.\jy-draftc.exe -v
.\jy-draftc.exe -h
.\jy-draftc.exe -c "<测试副本>\draft_content.json"
.\jy-draftc.exe -dc "<测试副本>"
.\jy-draftc.exe -ec "<测试副本>-plain"
```

按当前上游说明，省略输出路径时，解密/回加密分别在输入旁生成 `-plain` / `-enc` 副本。指定输出使用 `-o`；首次验证不覆盖原工程，也不自动进行结构升降级或成片导出。检查命令非零退出时先查原因，不继续执行后面的写入步骤。

### 与本次本机旧链路的区别

本次实际执行使用一个已有的旧式 `jy-draftc.exe`，通过本机Python包装脚本传入 `-d 输入 输出` / `-e 输入 输出`。该二进制没有可确认的发布标签，不能标成某个新版Release。包装脚本和二进制不在本技能仓库中。

当前上游用 `-dc` / `-ec`（也保留短别名）及 `-o` 输出参数，不能把旧包装脚本当作新版通用接口。新用户按自己下载包的 `-h`、README和运行时绑定配置；不要为了复现本次剪辑去复制作者机器路径或未知旧工具。

## 首次实际写入前的副本验证

1. 保存目标草稿，确认无未保存修改；复制完整工程到独立位置并记录原文件哈希。先识别真正生效的时间线，不能只改根目录一个文件。
2. 检查工程是明文还是加密。明文可直接解析；加密则先对副本解密，确认JSON可解析及素材引用可访问。
3. 先做无内容改动的“解密 → 回加密 → 再解密”检查，比较JSON数据是否一致；不要求随机加密后的字节相同。
4. 再对副本做一处小修改，检查实际合成、工程打开、保存重载后该改动仍在。确认新增字体/效果资源存在；“字段写进JSON”不等于剪映识别。
5. 可逆流程与兼容性成立后，按用户授权修改最新正式稿；写前重新核对哈希，发现变化就重读合并。交付说明分别列文件、静帧、声音、原生重载及连续播放验证情况。

只做分析方案时不需要安装以上全部工具，也不需要运行加解密。没有原生播放证据时如实留待用户看片，不能为补证据擅自控制桌面。

## 常见未就绪情况

| 现象 | 检查与下一步 |
|---|---|
| 找不到ffmpeg/ffprobe | 检查可执行文件与PATH；不能只确认Python包装库已安装 |
| 有Python却提示模块缺失 | 核对当前解释器，给同一解释器安装实际所需库 |
| 找不到videoeditor.dll | 核对JY_INSTALL_DIR是否指到具体版本目录，软件升级后旧路径可能失效 |
| 加解密提示版本/入口不兼容 | 对照工具发布包的运行时要求，停止写入，不能靠强制覆盖继续 |
| 旧命令或包装脚本报参数错误 | 根据本包帮助调整输入输出参数，不直接套另一个版本的命令 |
| 解密成功但读不到预期镜头 | 检查有效时间线、复合片段及实际素材引用，不能只看根稿 |
| 素材/字体/动画在别人机器丢失 | 补齐合法可用资源并重定位路径，本技能下载不包含这些资源 |
| 蒙版/转场参数在保存后消失 | 检查当前剪映的原生保存结构及资源，不能以加密回环判兼容 |
| 视频与独立配音重复叠响 | 识别内嵌声与独立音轨，保留唯一对白，关闭重复来源 |
| 回读一致但播放不连贯 | 文件检查不覆盖动作、口型、声音和阅读节奏，仍需连续带声审片 |

本页命令已对照上游文档及本次本机调用方式核查，未在一台全新电脑上完成安装及兼容性实测。使用者需要完成上述副本验证，才能确认其环境可直接修改草稿。

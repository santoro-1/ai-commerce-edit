# 个人偏好与项目预设

这是创建skill时用户的工作偏好，不是所有视频的审美定律。当前任务的明确要求优先；新项目可先沿用合适的默认值，再按画幅、素材和用户反馈调整，不逐项重新问已知偏好。

## 可沿用的工作偏好

- 用户可能提供AI视频、实拍、商品图片或手剪草稿；同一分镜可能多条候选，由助手实际比较和选择。
- 需要完整成片的镜头组织、节奏和表现力，不能止于按编号拼接；批量视频要求按主体差异化。
- 交付可编辑草稿。保留独立片段、关键帧、文字和必要图层，不用整条压成一个视频替代工程。
- 优先直接处理文件，不为展示操作而强行操控电脑；工具和版本不绑定，用户可有现成解密程序。
- 修改以用户最新保存稿为准。用户已修的字幕、声音、复合片段、配乐和删改都先检查，不用历史版本恢复。
- 已有项目精修通常就地改最新版本，不自动不断新建V几；备份放独立位置，名称按用户要求便于辨认。
- 台词字幕默认单行、按语义断句，可省一般标点；不丢小数点、单位、型号等有意义的符号。优先保留当前项目最新确认的字体、字号、位置和缩放，长句按声音与语义分屏，不靠自动换行或随意缩小解决。新项目再按安全区与关键画面定版式。
- 普通卖点默认在字幕所在阅读区域用短词、颜色或字重强调，避免重复整句和独立长花字；这是本用户的默认偏好，当前脚本或用户另有明确设计时按本次要求处理。
- 字幕、花字、脚本字卡分别处理。花字通常不套大黑底；福利选择、参数比较、步骤等信息需要独立字卡时可单独设计，不强套普通字幕样式，背景在文字下方。具体字卡版式由当前内容决定。
- 需要剪映字幕或视频动画时优先使用真实可用的原生动画，入场后留稳；不把整幅画面缩放当作所有动画的替代。资源不足时说明限制并选择可行手法，不虚报原生效果已经添加。
- 转场逐接点判断，避免全片同一种短叠化，也不规定效果数量或强行延长所有转场。
- 颜色先逐镜校正，再匹配相邻镜头；保留商品本色，不将某条的肤色、冷暖或饱和度参数当成整批预设。
- 默认保留完整台词、原声顺序和原语速；用户已确认的变速以最新稿为准。标注目标时长与完整声音冲突时先说明取舍，不靠加速或截句强凑时长。
- 检查视频内嵌声与独立人声是否重复；音量处理要计入已有增益和响度效果，不机械给所有源再做一次处理。
- 用户只要BGM建议时推荐类型；未要求添加时不新增曲目，保留用户已加音乐。必要提示音也以当前授权范围和人声可懂度为准。
- 单纯缩放优先段内关键帧。为叙事、动作或素材替换可以切片，不把这条偏好理解为整片不得剪切。
- 用户愿意提供新素材；缺镜头时给具体用途和画面要求，不因现成素材不足就机械拉近拉远。

## 仅属于三九案例的参数

| 当时约定 | 新项目如何处理 |
|---|---|
| 剪映5.9.0、竖屏1080×1920、24帧 | 用当前项目和用户要求；不要求升级或退回某版 |
| 台词12号、单行、省一般标点 | 可作为起点，实际预览可读性和字号映射需验证 |
| 台词Y=-1100、花字X=0/Y=1300 | 是当时版式；JSON坐标含义依软件、画布及项目，不直接当像素或跨版本常量 |
| 开头入场1秒、原转场延长 | 当时反馈；不把每个镜头和每个转场都设成同一时长 |
| 逐分镜花字、指定成分字卡 | 当时明确要求应兑现；新品类按当前脚本和用户要求决定密度 |
| 999PYP产品名、无新增音乐的早期要求 | 不迁移品牌名；声音授权随任务推进，保留用户后来新加的BGM |

## 反馈如何保存

用户要求更新经验时，把事实和推断分开：

> 项目/片段；原问题；画面或声音依据；采取的办法与理由；用户反馈；已验证范围；适用条件。

局部反馈先作为案例；重复且明确的个人选择可更新本页；只有跨场景仍成立的判断才放核心方法。未获得后续审片反馈的方案保留待验证标记。更新技能不会自动重剪历史工程。

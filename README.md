# ai-commerce-edit
我的电商skill

根据脚本和已有AI视频、实拍、商品图片或手剪草稿，制作电商产品短片，交付可继续编辑的工程。当前技能版本：**0.2.0**。

## 能做什么

- 每条重新核对对应脚本、实际素材与最新草稿，按内容分析剪法。
- 保留用户有效的段落安排、最新字幕、声音、变速及局部设计。
- 完整第一版纳入必要的字幕动效、转场、逐镜颜色和声音处理，再按看片反馈精修。
- 区分普通字幕、短卖点强调和独立信息字卡，按画面与信息需要决定手法。
- 优先文件方式工作，非必要不控制电脑；分开说明文件、静帧、连续播放与编辑器重载的验证结果。

纯口播去停顿、参考广告复刻生成、视频生成提示词及单独导出有各自的工作流程，不以本技能为主。

## 安装与调用

可在Codex中让 `$skill-installer` 从此仓库安装根目录的技能：

```text
使用 $skill-installer，从 https://github.com/santoro-1/ai-commerce-edit
安装仓库根目录的技能，名称为 ai-commerce-edit。
```

也可以下载仓库，将 `SKILL.md`、`agents/` 和 `references/` 一起放入当前Codex支持的技能目录下的 `ai-commerce-edit/` 文件夹。官方文档列出的用户级目录为 `~/.agents/skills/`；已有环境若使用其他受支持目录，以实际发现结果为准，不要重复安装同名技能。

在新聊天明确调用 `$ai-commerce-edit`。Codex可检测技能变化；若列表未刷新，可重启后再检查。参见[官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

## 开剪前提供什么

1. **脚本**：文件或可访问路径，表格中的具体标题；容易重名时加工作表或对应台词。
2. **最新草稿**：项目名及位置，说明已保存；已有手剪安排也请保留。
3. **素材**：所在位置，或说明已全部放入草稿；新增镜头停在末尾时说明它们的用途。
4. **当前产品口径**：卖点、参数、活动及禁用说法；脚本与补充信息冲突时指定以哪个为准。
5. **本轮范围**：先方案还是按已确认方案执行，哪些区域暂不改，字幕参考哪份、是否自行添加BGM。

### 新聊天示例

```text
使用 $ai-commerce-edit，剪辑《脚本标题》。
脚本：<文件路径及对应标题>
最新剪映草稿：<项目名和路径，已保存>
素材：<素材目录，或已全部放入草稿>
产品和活动：<当前确认信息，或见脚本>
字幕沿用当前草稿最新样式，保留完整台词。
先读脚本和最新稿，给针对性方案，等我确认再改。
非必要不控制电脑，BGM我自己加。
```

规则和案例保存在技能文件中；历史聊天里的全部细节、草稿位置及新素材状态不会随调用名自动转移。只说“按上一条来”不足以确认新项目的具体参数。

## 运行条件与验证边界

这是工作方法与案例技能，不是剪映控制插件。仓库不附带剪映草稿读写/解密工具、字体、付费效果资源、项目素材或账号凭据。实际读写工程需要当前环境具备相应工具，执行前先检查可用性和版本兼容性。

0.2.0已做技能结构、引用和修改范围检查，并进行十项场景推演；尚未完成升级后新视频的实际剪辑与用户审片验证。文件校验不能代替原生连续带声播放。

## 后续维护

先读 [HANDOFF.md](HANDOFF.md)。改技能前确认具体范围并备份，保留原案例与用户修改；升级后检查结构、引用和真实行为，再同步已确认内容到此仓库。

安装副本不会自动从GitHub更新，修改也不会自动推送。维护时先对比当前安装副本、仓库工作区和远端，合并最新变化，再提交并正常推送；不覆盖他人提交、不强制推送。仅讨论方案不触发修改或同步。
